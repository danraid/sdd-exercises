# Spec-Driven Development | Exercises and laboratories

Companion repository for the 12-chapter textbook *Spec-Driven Development: Engineering Software from Verifiable Specifications*.

This repository contains the original chapter laboratories, code listings, exercises, and model answers. Each lab is a synthetic teaching exercise, not production code; model answers describe expected properties, not evidence of execution. Run the tests locally, record actual output, and treat policy approval as a separate decision.

See the [textbook source](https://github.com/danraid/sdd) and the chapter-specific folders below.
