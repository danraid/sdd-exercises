## Reproduction

Use Python 3 and the standard library unless a chapter explicitly specifies otherwise. Execute commands in the directory stated in the laboratory. Record interpreter, hashes, test output and return code. Do not assume that illustrative or expected outcomes have been executed. The policy approval gate remains separate from runnable checks.
