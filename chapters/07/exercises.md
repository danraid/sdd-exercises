# Chapter 07 | Exercises and knowledge checks

**1. Assumptions and trade-offs.** Explain why validation precedes delegation. Describe the specification, storage and integration changes needed if descriptions must be retained in records. A satisfactory answer distinguishes that stronger policy from the present wrapper.

**2. Invariant and failing test.** Implement the delegate-first defect and identify the assertion that fails. Explain why an exception-only assertion can pass despite the defect.

**3. Extend and verify.** Add a synthetic requirement that a description must not exceed 100 characters. Add a new test with accepted and rejected boundary values, update the specification and validator expectations, and capture a restored passing run. State whether the new rule is approved or merely proposed.

**4. Inspect traceability.** Link REQ-005 to an existing but irrelevant test. Explain what name resolution establishes and what independent assertion review must establish.
